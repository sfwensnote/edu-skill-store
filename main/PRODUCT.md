# Educational Skill Builder

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
按用户已授权的“简单路径、直接执行”选择 React + TypeScript + Vite、Node.js + Express、SQLite。设计生成与教学对话各一个可配置模型接口。无需微服务或智能体框架。

## Users
技术能力有限的在职教师。教师通过自然语言描述需求、上传材料、确认方案和试用完成任务。

## Product Purpose
将教师教学意图转化为可执行 Educational Skills，并对生成智能体进行教育与技术双重验证。

平台同时提供教师助手社区。教师可以浏览公开助手、理解其教学方法并进行只读试用；创建助手是社区中的核心功能，而不是唯一入口。

## Capabilities and Constraints
通用流程固定为六步：教学需求 → 确认理解 → 教学策略 → 教学材料与助手生成 → 检测与试用 → 确认使用。
数学一元一次方程为首个明确标记的示例，不限制真实模型模式的学科输入。
用户要求一周 Demo、简洁模块、低耦合、解释清楚。教学材料只上传，不要求分类或标签。
后续对话使用用户已有微调模型。模型地址、名称、密钥尚未提供；演示模式必须始终可辨。
账户功能限本地 Demo 注册登录；启用仅表示工作台内可继续使用，不等于发布到学校。
社区首版使用明确标记的数学示例数据，不提供虚构使用量、评分或教学效果数据。

## Evidence on Hand
当前聊天已确认的方案；原始文件《教学skill生成与验证.docx》中的一句项目目标。内置数学内容为自编示例。

## Product Principles
- 自然语言优先，不让教师配置 AI 技术参数。
- 社区助手先展示教学对象、问题与方法，再允许试用，不把助手包装成无法解释的黑箱商品。
- 六步严格相邻跳转，历史项目进入最近未完成步骤。
- 每一步一个主要动作。
- 教学解释写成可观察行为，不以理论名词代替执行步骤。
- 先材料小文本上下文，之后按真实需求扩展。
- 检测与试用依据可追溯；演示结果不视为模型能力证明。
